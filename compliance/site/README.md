# Compliance site kit

Shared, framework-neutral React pages for the public compliance records served at `/compliance` on [internet.dev](https://internet.dev/compliance) and [users.garden](https://users.garden/compliance). Both sites render the same pages from identical copies of this directory.

The canonical copy is `apis/compliance/site/`. The copies at `www-internet-v3/compliance/site/` and `www-users-garden/compliance/site/` are generated; edit the canonical copy and sync. The workflow for adding or changing a page lives in the `compliance-pages` skill: `apis/.claude/skills/compliance-pages/SKILL.md`.
